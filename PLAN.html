Request flow and what gets logged

Five acceptance criteria (draft)

1. Reachableextension
URL returns label + confidence for a 50-word post in ≤ 5 s (warm). 3/3.
2. Loggedextension
Every request → 1 JSONL line with ts, input, label, confidence, latency_ms. 10/10 per trial, 0 missing fields.
3. Warm latencyextension
Median latency_ms ≤ 500 ms over 20 requests.
4. Cold startextension
First request after the Space sleeps answers in ≤ 60 s.
5. Quality holdssystem
Macro-F1 ≥ 0.60 on test set; hosted = local predictions on ≥ 19/20 posts.
Out of scope
New labels, hardening (retries, rate limits, bad input), auth, UI polish.
