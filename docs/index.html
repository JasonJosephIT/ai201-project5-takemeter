The model is a fine-tuned DistilBERT running on a Hugging Face Space (free CPU). If it has been asleep, the first answer can take up to a minute. Test-set macro-F1 is 0.36, so expect mistakes; it is best at spotting ads. Every request is logged by the Space, including the text you send. Source on GitHub.
